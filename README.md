Casino Game Collection

Overview
This project is a text-based casino game collection, featuring Craps, Roulette, and a Random Numbers game. Each game offers various betting options, and players can continue as long as they have chips to wager.

Games Included
Craps: Includes Pass Line, Don't Pass Line, Come Bet, and Odds Bets.
Roulette: Bet on Single Numbers, Columns, Red/Black, and Odd/Even.
Random Numbers: Enter 10 numbers between 0 and 10,000 and try to match the generated numbers.
Key Features
Multiple Games: Play Craps, Roulette, or a Random Numbers guessing game.
Betting System: Various bet types available, with different payouts and rules.
Chips Management: Play as long as you have chips to bet.
